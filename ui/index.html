Перевод с экрана

Выдели текст на экране — перевод появится рядом. Текст распознаёт сама Windows прямо на компьютере; в переводчик уходит только распознанный текст, не картинка.

Горячие клавиши

Отметь Ctrl / Alt / Shift / Win и выбери клавишу. «Выкл» — отключить сочетание.

Языки и переводчик

Как показывать

Нет нужного языка текста?

Windows распознаёт языки, которые у неё установлены. Японский, китайский, корейский и другие ставятся бесплатно: Параметры → Время и язык → Язык и регион → Добавить язык. Или в PowerShell от имени администратора: Add-WindowsCapability -Online -Name "Language.OCR~~~ja-JP~0.0.1.0". После установки перезапусти плагин.
Не видно перевода в игре? Включи в игре режим «окно без рамки» (borderless): поверх эксклюзивного полноэкранного режима Windows ничего не показывает.
